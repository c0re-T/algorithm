# LeetCode 53 最大子数组和（初值取 `nums[0]` 而不是 0，是为了全负数组）

> 对应程序：[LeetCode53_MaximumSubarray.java](./LeetCode53_MaximumSubarray.java)
> `main` 用 `[-2,1,-3,4,-1,2,1,-5,4]`，实测输出 `6`（子数组 `[4,-1,2,1]`）。

---

## 一、Kadane：每步只做一个二选一

```java
currentSum = Math.max(nums[i], currentSum + nums[i]);   // 接着上一段，还是从自己重新开始？
maxSum = Math.max(maxSum, currentSum);
```

`currentSum` 的含义是"**以 i 结尾**的最大子数组和"。以 `i` 结尾的段只有两种来源：接在 `i-1` 结尾的那段后面，
或者只含 `i` 自己。取大者即可 —— 这就是 `O(n)` 的全部。

逐轮走他的用例：

| i | nums[i] | currentSum | maxSum |
| --- | --- | --- | --- |
| 0 | −2 | −2（初值） | −2 |
| 1 | 1 | max(1, −1) = 1 | 1 |
| 2 | −3 | max(−3, −2) = −2 | 1 |
| 3 | 4 | max(4, 2) = 4 | 4 |
| 4 | −1 | 3 | 4 |
| 5 | 2 | 5 | 5 |
| 6 | 1 | **6** | **6** |
| 7 | −5 | 1 | 6 |
| 8 | 4 | 5 | 6 |

第 2 步值得注意：`currentSum` 从 1 掉到 −2，但 `maxSum` 停在 1 —— **"当前段"和"历史最好"是两个变量，不能只留一个**。

## 二、两个初值都取 `nums[0]`，是给全负数组留的

把 `currentSum` / `maxSum` 的初值改成 0（很多人的写法），实测：

| 数组 | 正确（他的写法） | 初值写 0 |
| --- | --- | --- |
| `[-2,-1,-3]` | **−1** | **0** ✗ |
| `[-1]` | −1 | 0 ✗ |
| `[-5,-2]` | −2 | 0 ✗ |
| `[2,-1,2]` | 3 | 3 ✓ |

固定种子 20,000 组随机（长度 1..8、值域 −5..5）：**两种初值不同 2,086 组**，全落在"所有元素都负"这一类上。
题面允许全负（`nums[i] ∈ [-10⁴, 10⁴]`，长度 ≥ 1），所以初值取 0 是实打实的 bug；取 `nums[0]` 才正确。

## 三、差分对拍与边界

```
   20,000 组随机 ：与 O(n²) 暴力不同 0 组
   空数组       ：ArrayIndexOutOfBoundsException（nums[0] 直接取，题面保证长度 ≥ 1）
   单元素       ：返回该元素本身（含负数）
   全负数组     ：返回最大的那个负数（第二节）
```

## 四、代价

| 规模 | Kadane | 两重循环 |
| --- | --- | --- |
| 1,000,000 | **4 ms** | **216,096 ms**（3.6 分钟，真的跑完了） |
| 3,000 | 0 ms | 若干 ms |

100 万这一档差了 **54,024 倍**，而且暴力并不是"跑不完"——它跑完了，只是花了三分半。
这题 n 上限 10⁵，暴力约 5×10⁹ 次加法，属于"能跑但会被判超时"的典型。

## 五、和 560 题的分工

同样问"子数组"，53 是"最大**和**"、560 是"**个数**"：

| | 53 | 560 |
| --- | --- | --- |
| 问什么 | 最大和 | 有多少段的和等于 k |
| 能不能用"当前段"滚动 | **能**（只留一个 currentSum） | 不能（要记住每个前缀和出现的次数） |
| 为什么 | 最优子结构：以 i 结尾的最优解只依赖以 i-1 结尾的最优解 | 要计数所有历史前缀和 |

**53 能压成一个变量，560 必须开一张表** —— 这是"最优化"和"计数"两类 DP 的分水岭。

## 六、一句话记住

```
   每步二选一：接着上一段，还是从自己重新开始；currentSum 和 maxSum 必须分开存；
   初值取 nums[0] 而不是 0：全负数组上初值 0 会给出 0（20,000 组随机里 2,086 组出错）；
   20,000 组与暴力 0 差异；n=100 万 Kadane 4 ms、暴力 216 秒（54,024 倍）；
   它和 560 的区别是"最优化 vs 计数"，所以一个能滚成一个变量、一个必须开哈希表。
```
