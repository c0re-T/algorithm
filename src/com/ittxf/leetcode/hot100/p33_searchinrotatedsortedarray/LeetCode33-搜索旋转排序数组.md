# LeetCode 33 搜索旋转排序数组（二分：先认有序的那半边）

> 对应程序：[LeetCode33_SearchInRotatedSortedArray.java](./LeetCode33_SearchInRotatedSortedArray.java)
> `main` 传的是 `{4,5,6,7,0,1,2}` 找 0、`{6,7,8,0,1,2,3,4,5}` 找 2，实测：
>
> ```
> 4
> 5
> ```

---

## 一、骨架还是二分，多了一步"哪半边一定有序"

```java
if (nums[lt] <= nums[mid]) {          // 左半边有序
    if (nums[lt] <= target && target < nums[mid]) rt = mid - 1;
    else lt = mid + 1;
} else {                              // 右半边一定有序
    if (nums[mid] < target && target <= nums[rt]) lt = mid + 1;
    else rt = mid - 1;
}
```

旋转数组从中间切开，**至少有一半是升序的**。先靠 `nums[lt] <= nums[mid]` 认出左半边，再看 target 在不在 `[lt, mid)` 这个区间里；不在就整段丢掉。右半边同理，区间是 `(mid, rt]`。命中判断 `nums[mid] == target` 放在最前面，所以两边都不用重复处理等号。

## 二、`<=` 里的 `=` 不是装饰

`nums[lt] <= nums[mid]` 的等号在互不相同的数组上只在 `lt == mid` 时成立（区间只剩一两个元素）。去掉它实测：

| 对拍 | 差异 |
| --- | --- |
| 穷举 n=1..8 的所有旋转 × 目标 −1..n（276 组） | 6 组 |
| 20,000 组随机互不相同的旋转数组 | 388 组 |

最短反例只要两个数：

```
[1, 0] 找 0
原版          -> 1
去掉 <= 的 =  -> -1
```

`lt=0, mid=0` 时 `nums[0]=1` 不小于 `nums[0]`，代码误判"右半边有序"，把唯一的答案丢进了另一支。**能命中的普通用例表现完全正常**，只有这种贴边的小区间会露馅。

## 三、重复值：不保证找到，但找到的通常合法

题面保证互不相同。放宽成重复值后实测 20,000 组：

| 结果 | 组数 |
| --- | --- |
| 和线性扫描一致（返回第一个下标） | 11,415 |
| 返回了一个合法但不是第一个的下标 | 8,489 |
| **目标明明存在却返回 −1** | **96** |

```
[2,2,2,0,2] 找 2 -> 2（第一个在 0，2 也是合法下标）
11 个元素那组随机数据找 2 -> -1，而 2 存在于下标 3、4
```

原因是 `nums[lt] <= nums[mid]` 在重复值上分不清"左段有序"还是"左右相等"，会往错误的一侧收。第 81 题（含重复值）不能直接用这份。

## 四、边界与副作用

| 输入 | 结果 |
| --- | --- |
| `{}` | −1（`rt = -1`，循环一次都不进） |
| `{7}` 找 7 / 找 3 | 0 / −1 |
| 有序未旋转 `{1,2,3,4,5}` 找 3 / 找 9 | 2 / −1 |
| `null` | `NullPointerException: Cannot read the array length because "<parameter1>" is null` |

同一数组连调两次给同样的答案，入参只读；`mid = lt + (rt - lt) / 2` 不会溢出。

## 五、代价：log n

n=10,000,000 的旋转数组上连跑 100 万次查找，实测 **135 ms**（约 135 ns/次，`ceil(log₂ 10⁷) = 24` 轮）。和普通二分的唯一区别就是每轮多一次比较。

## 六、一句话记住

```
   旋转数组二分：先判断哪一半有序，再看 target 在不在那一半里；
   nums[lt] <= nums[mid] 的等号只在 lt == mid 时生效，去掉后 [1,0] 找 0 从 1 变 -1，20,000 组随机错 388；
   20,000 组互不相同的旋转数组与线性扫描 0 差异；
   重复值上会"找到但不是第一个"（8,489/20,000），也可能漏（96/20,000）—— 第 81 题另写；
   空数组返回 -1，null NPE，入参只读；
   10^7 数组上 100 万次查找 135 ms。
```
