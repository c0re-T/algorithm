# LeetCode 543 二叉树的直径（算深度时顺手更新答案，直径数的是边）

> 对应程序：[LeetCode543_DiameterOfBinaryTree.java](./LeetCode543_DiameterOfBinaryTree.java)
> `main` 那棵树（1 的左 2、右 3，2 的左 4、右 5），实测：
>
> ```
> 二叉树的直径: 3
> ```
>
> 最长路径是 `4→2→1→3` 或 `5→2→1→3`，**4 个节点、3 条边**。题目要的是边数。

---

## 一、和 `p104` 只差一行

```java
private int getDepth(TreeNode node) {
    if (node == null) return 0;
    int leftDepth  = getDepth(node.left);
    int rightDepth = getDepth(node.right);
    maxDiameter = Math.max(maxDiameter, leftDepth + rightDepth);   // ← 只多了这一行
    return 1 + Math.max(leftDepth, rightDepth);
}
```

`p104` 求最大深度，返回 `max(左,右)+1`；这里在同一个后序位置上顺手算一次 `左+右`，那就是**经过当前节点、向两边各伸一条最长腿**的路径长度。任何一条路径都必然有唯一一个"最高点"，在那个点上它正好被算成 `左深度+右深度`，所以遍历一遍所有节点取 max 就覆盖了全部路径。

两个量的口径不一样，这是最容易写错的地方：

- `getDepth` 返回的是**节点数**（空树 0，单节点 1）；
- `leftDepth + rightDepth` 恰好是**边数**（左腿有 leftDepth 个节点 = leftDepth 条边连到当前节点，右腿同理）。

所以不需要再减 1。实测在更新式里多加一个 `+1`：`main` 那棵树给 4（应为 3），20,000 组随机树**全部 20,000 组都错** —— 这是口径错误，不是边界错误，任何非空树都会多算一条边。

反过来，`return` 里漏掉 `+1`（写成 `Math.max(leftDepth, rightDepth)`）实测所有输入都给 0：深度永远从 0 长不起来。

## 二、为什么必须有全局变量

很自然会想"直径不就是根的左深度 + 右深度吗"，写成：

```java
return getDepth(root.left) + getDepth(root.right);   // 只看根
```

`main` 那棵树恰好给 3（正确答案），**但 20,000 组随机树里错 1,022 组（5.1%）**。反例是"最长路径完全躲在某一棵子树里"：根只有一条腿，另一条腿很短，而左子树内部自己有一条很长的路。只看根就把它漏了。

`maxDiameter` 的作用就是让每个节点都有机会上报自己那个拐点，最后取最大的。这和 `p124` 的 `maxSum` 是同一个模式：**返回值给父亲用（单边），全局变量记答案（双边）**。

## 四、`maxDiameter` 是实例字段，而且从不复位

同一个 `Solution` 依次调用：

```
main 那棵树      -> 3（真值 3）
两节点树         -> 3（真值 1）  ← 上一次的答案留下来了
null            -> 0（开头 guard 直接返回，没走 getDepth）
单节点树         -> 3（真值 0）  ← 又是历史最大值
```

`maxDiameter = Math.max(maxDiameter, ...)` 只增不减，所以**第二次起返回的是历史最大直径**。`main` 里只调一次，永远测不出来。修法是把 `maxDiameter = 0` 放进 `diameterOfBinaryTree` 开头，或者干脆改成局部变量 + 参数传递（`p437` 就是这么做的，连调三次不泄漏）。

## 五、递归深度

| 形状 | 节点数 | 直径 | 耗时 |
| --- | --- | --- | --- |
| 满树（高 10） | 1,023 | 18 | 0 ms |
| 满树（高 16） | 65,535 | 30 | 0 ms |
| 满树（高 20） | 1,048,575 | 38 | 2 ms |
| 右斜链 | 50,000 / 100,000 / 200,000 | — | `StackOverflowError` |

满树的直径是 `2×(h-1)`（从最左叶到最右叶经过根），高 20 → 38，和实测一致。100 万节点 2 ms；同样节点数换成一条链就爆栈，和 `p104` 完全同一档（栈深度 = 树高）。

## 六、一句话记住

```
   getDepth 返回节点数，leftDepth + rightDepth 恰好是边数，不要再 ±1；
   更新式多加 +1：main 树给 4，20,000 组全错；return 漏掉 +1：全部给 0；
   只看根的左+右：main 树恰好对，随机数据错 1,022/20,000（5.1%）；
   20,000 组与"无向图两次 BFS"参考 0 差异；
   maxDiameter 是实例字段不复位：大树之后调两节点树仍给 3（真值 1）；
   满树 100 万节点 2 ms、直径 38，斜链 5 万爆栈。
```
