# LeetCode 198 打家劫舍（滚动 DP + 三道长度守卫）

> 对应程序：[LeetCode198_HouseRobber.java](./LeetCode198_HouseRobber.java)
> `main` 跑两组示例，实测：
>
> ```
> 4
> 12
> ```

---

## 一、`dp[i] = max(不偷这家, 偷这家 + dp[i-2])`

```java
int prev1 = nums[0];                  // dp[i-2]
int prev2 = Math.max(nums[0], nums[1]); // dp[i-1]
for (int i = 2; i < nums.length; i++) {
    curr = Math.max(prev2, prev1 + nums[i]);
    prev1 = prev2;
    prev2 = curr;
}
```

不能偷相邻两家，所以到第 i 家只有两种选择：跳过它（继承 `dp[i-1]`），或者偷它并接上 `dp[i-2]`。只依赖前两项，滚动成两个变量，`O(n)` 时间 `O(1)` 空间。

对拍用了两条独立参考：

- 长度 0..18 的 20,000 组随机，与**枚举所有 `1<<n` 个子集、剔掉含相邻位的掩码**的暴力比较：**0 处差异**
- 长度 19..200 的 3,000 组随机，与 `dp[n+1]` 数组版比较：**0 处差异**

## 二、三道守卫各自挡住什么

```java
if (nums == null || nums.length == 0) return 0;
if (nums.length == 1) return nums[0];
...
if (nums.length == 2) return prev2;
```

| 删掉的守卫 | 20,000 组随机里的错误 | 最小例子 |
| --- | --- | --- |
| `length == 2` | **970 处** | `[21,22]` 返回 **0**，应为 22 |
| `length == 1` | **1,024 处**（含崩溃） | `{5}` 抛 `ArrayIndexOutOfBoundsException` |

`length == 2` 那道最容易漏：长度为 2 时循环 `i = 2` 一次都不执行，`curr` 保持初始值 0，于是**返回 0 而不是 max**。`{1,2}` 实测就是 0。

`length == 1` 那道挡的是 `Math.max(nums[0], nums[1])` 里的 `nums[1]` —— 长度为 1 时直接越界。

## 三、`Math.max` 和 `prev1` 都不能动

| 变体 | 差异 | 第一个反例 |
| --- | --- | --- |
| `curr = prev1 + nums[i]`（去掉 `Math.max`） | **10,415 / 20,000** | 17 个元素的数组返回 140，应为 159 |
| `curr = max(prev2, prev2 + nums[i])`（`prev1` 写成 `prev2`） | **16,263 / 20,000** | 同一数组返回 254，应为 159 |

去掉 `Math.max` 就变成"必须偷第 i 家"，丢掉了跳过的选项；`prev1` 写成 `prev2` 则允许偷相邻两家，254 明显超过了合法上限。

## 四、边界

| 输入 | 结果 |
| --- | --- |
| `null` | `0` |
| `{}` | `0` |
| `{5}` | `5` |
| `{1,2}` | `2` |
| `{2,1}` | `2` |
| `{0,0,0}` | `0` |

这题是少数**显式处理了 null** 的程序，不抛异常。

题面保证 `0 <= nums[i] <= 400`。如果允许负数，程序会返回负数：

| 输入 | 程序返回 | 允许"什么都不偷"的暴力 |
| --- | --- | --- |
| `{-5,-2}` | **-2** | 0 |
| `{-5,-2,-9}` | **-2** | 0 |

原因是 `prev1 = nums[0]` 强制偷了第一家，没有留"全不偷"的出口。题面范围内不构成问题。

int 溢出同样安静：`{2000000000, 0, 2000000000}` 返回 **2,000,000,000**，long 真值是 4,000,000,000 —— `prev1 + nums[i]` 溢出成负数，被 `Math.max` 丢掉了。

入参只读，同一数组连调两次结果一致。

## 五、实测代价

n=10,000,000、全部为 1（答案 5,000,000）：

| 版本 | 耗时 | 额外堆 |
| --- | --- | --- |
| 滚动变量 | **7 ms** | 0 |
| `dp[n+1]` 数组 | 21 ms | **38 MB** |

结果一致。滚动版省下的不只是时间，更是那 38 MB。

## 六、一句话记住

```
   dp[i]=max(dp[i-1], dp[i-2]+nums[i])，滚动两个变量，O(n) 时间 O(1) 空间；
   20,000 组子集掩码暴力 + 3,000 组数组版 DP 对拍都 0 差异；
   length==2 守卫删掉错 970 处（[21,22] 返回 0），length==1 守卫删掉 {5} 直接越界；
   去掉 Math.max 错 10,415/20,000，prev1 写成 prev2（允许偷相邻）错 16,263/20,000；
   null 和 {} 都返回 0，是少数显式处理 null 的程序；
   负数输入返回负数（{-5,-2} → -2），{2e9,0,2e9} 溢出后安静返回 2e9；
   n=1e7 滚动 7 ms vs 数组 21 ms，数组还要多 38 MB 堆。
```
