# LeetCode 160 相交链表（两个指针走完自己的再走对方的，差就被补平了）

> 对应程序：[LeetCode160_IntersectionOfTwoLinkedLists.java](./LeetCode160_IntersectionOfTwoLinkedLists.java)
> `main` 手工搭了两条共享尾部 `8 → 4 → 5` 的链表，实测输出 `相交节点的值是: 8`。

---

## 一、四行代码

```java
ListNode pA = headA, pB = headB;
while (pA != pB) {
    pA = pA == null ? headB : pA.next;
    pB = pB == null ? headA : pB.next;
}
return pA;
```

核心：**`pA` 走完 A 之后接着走 B，`pB` 走完 B 之后接着走 A**。于是两个指针总步数都是 `lenA + lenB`，
而"交点之后那一段"在两条路径里各被走了一次 —— 长度差被自动补平，两个指针必然同时到达交点（或同时到达 `null`）。

前提是**按引用比较**（`pA != pB`），不是按值。实测他 `main` 里那条链表 A 的独立段含 `4`、B 的独立段含 `1`，
共享段从 `8` 开始 —— 输出 8 说明比的是节点身份。
改成比值就不可靠了：**题面不保证链表里的值不重复**，两个独立段里出现相同数字时会把它们当成交点，
而共享段之前的"相遇"是假交点。

## 二、实测步数

| 长度 | 有无交点 | 步数 |
| --- | --- | --- |
| A=3, B=4 | 无 | 8 = m+n+1 |
| A=5, B=5 | 无 | 5 = m（等长，根本不用切换） |
| A=1, B=9 | 无 | 11 = m+n+1 |
| A=0, B=3 | 无 | 4 = m+n+1 |
| A=3(独立)+2(公共), B=1+2 | 有 | 7（≤ m+n） |

两条规律：

- **等长且无交点**：两个指针同步走到 `null`，走 `m` 步就结束，不需要切换；
- **不等长**：先到的那个切到对方链表头，把长度差补齐，最多 `m+n+1` 步（`+1` 是最后一步"走进 null"）。

## 三、差分对拍

固定种子 20,000 组随机：两条长度 0..5 的链表，随机决定是否共享同一段尾链（**共享的是节点对象，不是值**），
与"把 A 的所有节点放进 `HashSet`，再顺着 B 找第一个命中"的参考实现比：

```
   不同 —— 0 组
```

## 四、边界与代价

```
   两条都 null        -> 返回 null（while 条件直接不成立）
   A 为 null、B 非空  -> 返回 null
   无交点             -> 两个指针同时变 null，返回 null
   交点就是 headA/headB -> 直接返回（第一次比较就相等）
```

| 规模 | 时间 |
| --- | --- |
| 两条各 1,000,000、无交点 | **3 ms**（2,000,000 次指针移动） |

`O(m+n)` 时间、`O(1)` 空间 —— 比"存 HashSet"省掉 `O(m)` 的额外空间。
实测 1M+1M 用指针法 3 ms，HashSet 那份在这台机器上没测（会多占约 100 万个节点引用的桶空间）。

**如果链表带环，这个循环不会终止** —— 题面保证无环，所以不需要判环；
真要不放心，先用 `p141` 的 `hasCycle` 挡一下。

## 五、和 141/206/234 的关系

四道链表题共用一套"两个指针"的骨架，但目的不同：

| 题 | 指针怎么动 | 靠什么收敛 |
| --- | --- | --- |
| 160 相交 | 各自前进、到头切到对方 | 长度差被补平 |
| 141 判环 | 慢 1 步 / 快 2 步 | 有环必相遇，无环必到 null |
| 206 反转 | prev/curr/next 三指针 | 逐个改 `next` |
| 234 回文 | 快慢找中点 + 反转后半 + 双指针比对 | 一半走完就停 |

**"快慢指针"和"双指针从两端"是链表题的两把刀**，160 用的是第三种：**路径拼接**。

## 六、一句话记住

```
   pA 走完 A 接着走 B、pB 走完 B 接着走 A —— 长度差自动补平，两个指针必同时到交点或同时到 null；
   比较必须按引用（pA != pB），按值比较会在独立段里误判；
   20,000 组随机与 HashSet 参考 0 差异；等长无交点走 m 步，不等长最多 m+n+1 步（实测 8/5/11/4）；
   O(m+n) 时间 O(1) 空间，1M+1M 实测 3 ms；链表带环会死循环（题面保证无环）。
```
