# LeetCode 41 缺失的第一个正数（把值当索引，原地"归位"）

> 对应程序：[LeetCode41_FirstMissingPositive.java](./LeetCode41_FirstMissingPositive.java)
> `main` 用 `{7,8,9,11,12}`，实测输出 `1`。要求 `O(n)` 时间 + `O(1)` 额外空间。

---

## 一、关键想法：值 `x` 应该待在索引 `x - 1`

答案一定落在 `[1, n+1]` 里（n 个格子最多装下 1..n；如果 1..n 都在，答案就是 n+1）。
所以只看 `[1, n]` 范围内的数，把它们**换到"值减一"的那个下标**上：

```java
while (nums[i] > 0 && nums[i] <= n && nums[i] != nums[nums[i] - 1]) {
    int temp = nums[nums[i] - 1];
    nums[nums[i] - 1] = nums[i];
    nums[i] = temp;
}
```

三个条件各管一件事：

| 条件 | 不管会怎样 |
| --- | --- |
| `nums[i] > 0` | 负数/0 不属于答案范围，跳过 |
| `nums[i] <= n` | 大于 n 的数放不进数组（`x-1 >= n` 越界） |
| `nums[i] != nums[nums[i] - 1]` | **防止重复值导致死循环**：目标位置已经是同一个值，再换就原地打转 |

第三个条件是这份实现里最容易漏的一处 —— 少了它，`[1, 1]` 在 `i=0` 时会把 `nums[0]` 和它自己交换
（目标位置就是它自己），while 永远退不出去（`nums[0]` 一直是 1、条件永远成立）。
**判的是"目标位置上的值和我是否相同"，不是"我是否已经就位"** —— 后者在重复值上也会误判。

用 `{7,8,9,11,12}` 走一遍：所有数都 > 5，while 一次都不进 → 第一趟检查不动 → 第二个循环发现
`nums[0] = 7 != 1` → 返回 **1** ✓（对这个输入，"缺失的第一个正数"确实是 1）。

## 二、为什么是 `O(n)`：每个数最多被换一次

一次交换就把一个数放到了它的最终位置（`nums[x-1] = x`），之后它不会再被移走。
所以内层 `while` 的总交换次数 ≤ n，外层 n 次 → `O(n)`。这是"循环排序（cyclic sort）"的通用论证。

## 三、差分对拍

固定种子 20,000 组随机（长度 0..9、值域 −5..9，包含空数组、负数、重复值）：

```
   与"把正数塞进 HashSet 再从 1 往上找"的参考实现不同 —— 0 组
```

## 四、边界

```
   空数组          -> 1        （两个循环都不进，返回 n+1 = 1）
   [1]             -> 2        （1 在正确位置上，返回 n+1）
   [1, 2, 0]       -> 3
   [7,8,9,11,12]   -> 1
   [-1,-2]         -> 1
   [2,1]           -> 3        （1..2 都在 → n+1）
```

空数组这一条不需要特判：`n = 0` 时两个循环都不进，直接 `return n + 1 = 1` ✓ 正好是正确答案。

## 五、它会就地重排入参

和 `p49_3sum`、`p56`、Floyd 那几处一样，这份实现**直接改调用方的数组**（cyclic sort 的本质）：

```
   调用前 [3, 4, -1, 1]
   调用后 [1, -1, 3, 4]
```

LeetCode 只看返回值，所以没问题；但调用方若之后还要用原数组，得先拷贝。
这也是"原地算法"的隐藏代价 —— 题面说"允许修改输入"时才是免费的。

## 六、代价与另一条路

```
   时间 O(n)（每个数最多归位一次）      空间 O(1)（只用了几个临时变量）
```

另一条符合题意但常数更大的路是"先排序再扫"（`O(n log n)`），或者"用 HashSet 从 1 往上找"（`O(n)` 时间但 `O(n)` 空间）。
**这题真正的考点是"把值域当索引"这个映射**，能不能想到它决定了空间复杂度。

## 七、一句话记住

```
   答案一定在 [1, n+1]，把 [1,n] 里的值换到"值减一"的位置上，再扫第一个不在位的索引；
   三个条件缺一不可，尤其 nums[i] != nums[nums[i]-1] 是重复值死循环的唯一屏障；
   20,000 组与 HashSet 参考 0 差异；空数组返回 1（n+1），不需要特判；
   它就地重排入参（[3,4,-1,1] -> [1,-1,3,4]），O(n)/O(1) —— 靠的是每个数最多归位一次。
```
