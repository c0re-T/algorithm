# LeetCode 118 杨辉三角（逐行递推 + 预分配容量）

> 对应程序：[LeetCode118_PascalsTriangle.java](./LeetCode118_PascalsTriangle.java)
> `main` 跑两组示例，实测：
>
> ```
> [[1], [1, 1], [1, 2, 1], [1, 3, 3, 1], [1, 4, 6, 4, 1]]
> [[1]]
> ```

---

## 一、两端填 1，中间取上一行相邻两数之和

```java
for (int i = 0; i < numRows; i++) {
    List<Integer> row = new ArrayList<>(i + 1);
    for (int j = 0; j <= i; j++) {
        if (j == 0 || j == i) row.add(1);
        else row.add(res.get(i - 1).get(j - 1) + res.get(i - 1).get(j));
    }
    res.add(row);
}
```

第 i 行有 i+1 个元素，总量 `n(n+1)/2`，时间就是这个量级。`j == 0 || j == i` 这个判断同时兜住了"第 0 行没有上一行"的情况 —— i=0 时 j 只能是 0，走的是填 1 分支，不会去 `res.get(-1)`。

用 `BigInteger` 独立算组合数 `C(i,j)` 对拍 numRows=1..34，共 **7,140 个格子，0 处不一致**。另外两条不变量也全部成立（numRows=1..30）：

- 每行左右对称：**0 处违反**
- 第 i 行元素之和等于 `2^i`：**0 处违反**

## 二、numRows=35 开始 int 溢出

中间那项增长最快，`C(34,17)` 是第一个越过 int 上限的数：

| 行下标 | numRows | `C(row, row/2)` 真值 | 程序返回 |
| --- | --- | --- | --- |
| 32 | 33 | 601,080,390 | 601,080,390 |
| 33 | 34 | 1,166,803,110 | 1,166,803,110 |
| **34** | **35** | **2,333,606,220** | **-1,961,361,076** |
| 35 | 36 | 4,537,567,650 | 242,600,354 |

负数格子会迅速扩散：numRows=35 有 3 个负数，36 有 9 个，37 有 15 个，38 有 21 个，39 有 29 个，40 有 43 个。题面限定 `1 <= numRows <= 30`，正好在安全区内。

## 三、预分配容量：预热后约 10%，但规模一大就量不出来

`new ArrayList<>(numRows)` 和 `new ArrayList<>(i + 1)` 是为了避开扩容拷贝。和完全不预分配的版本对比：

| 场景 | 预分配 | 不预分配 |
| --- | --- | --- |
| 冷启动第一次量（34 行 × 20 万次） | 754 ms | 611 ms |
| 预热后 6 轮（34 行 × 20 万次） | **494–528 ms** | 561–570 ms |
| 2000 行 × 200 次，第 1 轮 | 6,434 ms | 7,212 ms |
| 2000 行 × 200 次，第 2 轮 | 8,700 ms | 8,112 ms |

**第一行那个"预分配更慢"是 JIT 顺序噪声**：两个方法谁先跑谁吃亏。充分预热、正反两种顺序各跑 3 轮之后，34 行规模上预分配稳定快约 10%；但到 2000 行规模两轮互有胜负，**测不出稳定收益**。两个版本的结果在 numRows=0..34 上完全相同（0 处差异）。

numRows=2000 实测 10 ms，2000 行、**2,001,000 个格子**，正好等于 2000×2001/2（此时数值早已溢出，只有结构还有意义）。

## 四、边界：负数会抛异常，而不预分配的版本不会

| 输入 | 结果 |
| --- | --- |
| numRows=0 | `[]`（size=0） |
| numRows=1 | `[[1]]` |
| numRows=2 | `[[1], [1, 1]]` |
| numRows=-1 | `IllegalArgumentException: Illegal Capacity: -1` |
| numRows=-5 | `IllegalArgumentException: Illegal Capacity: -5` |
| numRows=Integer.MIN_VALUE | `IllegalArgumentException: Illegal Capacity: -2147483648` |

这是预分配带来的**唯一行为差异**：`new ArrayList<>(负数)` 直接抛异常，去掉容量参数的版本会安静地返回 `[]`。题面保证 numRows≥1，两者在合法输入上没有区别。

返回的每行都是可变的 `ArrayList`，行与行互不共享：把第 2 行的 `[0]` 改成 999 之后，该行变成 `[999, 2, 1]`，重新调一次 `generate(5)` 仍然拿到 `[1, 2, 1]`。

