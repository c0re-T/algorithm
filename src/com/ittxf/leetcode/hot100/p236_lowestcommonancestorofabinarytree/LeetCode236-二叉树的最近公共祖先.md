# LeetCode 236 二叉树的最近公共祖先（三行返回，靠"两边都非空"定拐点）

> 对应程序：[LeetCode236_LowestCommonAncestorOfABinaryTree.java](./LeetCode236_LowestCommonAncestorOfABinaryTree.java)
> `main` 那棵 9 节点树，p=5、q=1，实测：
>
> ```
> 3
> ```

---

## 一、整个算法只有三行

```java
public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
    if (root == null || root == p || root == q) return root;
    TreeNode left  = lowestCommonAncestor(root.left, p, q);
    TreeNode right = lowestCommonAncestor(root.right, p, q);
    return left == null ? right : right == null ? left : root;
}
```

递归函数返回的含义是："在这棵子树里，我找到的 p 或 q（或者它俩的 LCA）"。三种情况：

| 左支返回 | 右支返回 | 说明 | 返回 |
| --- | --- | --- | --- |
| null | null | 两个都不在这棵子树里 | null |
| 非空 | null | 两个都在左边（或只找到一个） | 左边那个 |
| null | 非空 | 同理 | 右边那个 |
| **非空** | **非空** | p 在一边、q 在另一边，**我就是拐点** | `root` |

最后一行是全部精髓：一旦左右都报告"我这边有货"，当前节点就是最近公共祖先，再往上不会再出现第二次"两边都非空"（因为上面收到的已经是合并后的单个节点）。

`root == p || root == q` 提前返回，处理的是**p 本身就是 q 的祖先**这种情况：走到 p 就直接返回 p，不再往下找 q。实测 p=5、q=4（4 在 5 的子树里）→ 5；p=q=5 → 5。

比较用的是 `==`（引用），不是 `val` 相等。题面保证节点值互不相同，但用引用才是语义正确的写法 —— 传进来的 p、q 本来就是树里的对象。

## 二、随机对拍

20,000 棵随机树 + 随机挑两个**树内**节点，与"给每个节点建父指针、然后让 p 一路向上跳并记录路径、q 也向上跳找第一个交集"的参考实现对比：

```
不一致 = 0
其中 3,487 组答案是 p 本身（p 是 q 的祖先）
其中 1,977 组 p == q
```

祖先情形占了 17.4%，所以那行 `root == p || root == q` 的提前返回不是可选优化，是正确性的一部分。

## 三、p 或 q 不在树里时，它会给出一个"看着对"的答案

这份实现**不验证 p、q 是否真的在树里**：

| 输入 | 他的返回 | 参考实现 |
| --- | --- | --- |
| p=6（树内）、q=一个不在树里的幽灵节点 | **6** | `null` |
| p、q 都不在树里 | `null` | `null` |
| `root = null` | `null` | `null` |

第一行是危险的：只找到一个就把那个当成答案返回了。调用方拿到 6 会以为"6 是它俩的 LCA"，而实际上 q 根本不存在。题面保证 p、q 都在树中，所以线上不触发；但如果要复用这份代码，得先自己确认存在性，或者改成"计数版"（找到两个才返回）。

## 四、递归深度

| 形状 | n | 结果 | 耗时 |
| --- | --- | --- | --- |
| 右斜链 | 50,000 | `StackOverflowError` | — |
| 右斜链 | 100,000 / 200,000 | `StackOverflowError` | — |
| 满树（高 20） | 1,048,575 | 正常 | 34 ms |

测斜链时我把 p、q 取成链上**最后两个节点**，逼它走完整条链 —— 如果 p、q 取在链头附近，第一层就命中 `root == p` 返回了，根本测不出深度（`p98` 那份笔记里踩过同样的坑）。

满树 100 万节点 34 ms，比 `p124` 的 2 ms 慢一个量级：这份最坏要访问全部节点（p、q 都在最深处），而且每层要做两次三元判断。时间 `O(n)`、栈 `O(h)`。

## 五、一句话记住

```
   左右都非空 → 我就是 LCA；只有一边非空 → 把那一边往上传；
   root == p || root == q 提前返回，处理"p 是 q 的祖先"（随机数据里占 17.4%）；
   20,000 组与父指针上跳参考 0 差异；
   不检查存在性：p 在树里、q 不在，会把 p 当答案返回（参考给 null）；
   比较用引用 ==；空树返回 null；
   满树 100 万节点 34 ms，斜链 5 万爆栈（测深度要把 p、q 放在链尾）。
```
