# LeetCode 234 回文链表（`O(n)` 时间 `O(1)` 空间，比完还要把后半段接回去）

> 对应程序：[LeetCode234_PalindromeLinkedList.java](./LeetCode234_PalindromeLinkedList.java)
> `main` 跑了三个案例，实测：
>
> ```
> 案例1 [1,2,2,1] 是否回文: true      执行后链表恢复: 1 -> 2 -> 2 -> 1
> 案例2 [1,2,3,2,1] 是否回文: true    执行后链表恢复: 1 -> 2 -> 3 -> 2 -> 1
> 案例3 [1,2,3,1] 是否回文: false
> ```

---

## 一、四步

```java
// 1. 快慢指针找中点：fast 走两步、slow 走一步
while (fast.next != null && fast.next.next != null) { slow = slow.next; fast = fast.next.next; }
// 2. 反转后半段
ListNode secondHalfStart = reverseList(slow.next);
// 3. 双指针比对
while (p2 != null) { if (p1.val != p2.val) { result = false; break; } p1 = p1.next; p2 = p2.next; }
// 4. 把后半段再反转回来，恢复原链表
slow.next = reverseList(secondHalfStart);
```

快慢指针的停止条件 `fast.next != null && fast.next.next != null` 决定了 `slow` 的落点：

| 长度 | slow 停在 | `slow.next` 是 |
| --- | --- | --- |
| 奇数（5） | 正中间（第 3 个） | 后半段第 1 个 |
| 偶数（4） | 前半段最后一个（第 2 个） | 后半段第 1 个 |

两种情况下 `slow.next` 都恰好是后半段的头，所以后面三步不用分奇偶。

**比对循环的边界用 `p2 != null`**（不是 `p1`）：偶数时两段等长、奇数时后半段短一个（中间那个不参与），
用 `p2` 走完正好把整条链表都比过。

## 二、它真的把链表恢复了（含提前 break 的情况）

第四节那步"恢复"很容易写成只在你比较顺利的时候执行 —— 这里 `break` 出来之后**恢复代码依然在**。
实测 6 种形状（把链表转回数组再比）：

| 输入 | 回文 | 调用前 | 调用后 | |
| --- | --- | --- | --- | --- |
| `[1,2,2,1]` | true | `[1,2,2,1]` | `[1,2,2,1]` | 结构完好 |
| `[1,2,3,2,1]` | true | `[1,2,3,2,1]` | `[1,2,3,2,1]` | 结构完好 |
| `[1,2,3,1]` | **false**（提前 break） | `[1,2,3,1]` | `[1,2,3,1]` | 结构完好 |
| `[1,2]` | false | `[1,2]` | `[1,2]` | 结构完好 |
| `[1]` / `[]` | true | 原样 | 原样 | 提前返回 |

**第三行是关键**：非回文时提前 `break`，`p2` 只走了一半，但 `secondHalfStart` 没变，
所以 `slow.next = reverseList(secondHalfStart)` 仍能把整段翻回原序。
这类"提前退出后还要做收尾"的逻辑，最容易被 `return false` 直接跳过 —— 他用 `result` 变量兜住了。

## 四、为什么不用"反转整个链表"或"存进 ArrayList"

- 存进 `ArrayList` 再双指针：`O(n)` 时间但 `O(n)` 空间，最简单、也最容易被面试追问"能不能 O(1) 空间"。
- 反转整条链表再比：会破坏原链表，而且只能比一次（比完两边都反了）。
- **这份实现的选择是"只反转后半段 + 比完再翻回来"**：时间 `O(n)`、空间 `O(1)`，代价是代码多了一步恢复。

## 五、边界与复杂度

```
   null / 单节点 -> true（第一行直接返回）
   [1,2]        -> false（长度 2、不相同）
   [1,1]        -> true
   全相同       -> true
```

时间 `O(n)`（找中点一趟、反转一趟、比对一趟、恢复一趟 = 4 趟，常数而已）；空间 `O(1)`（只用了几个引用）。

## 六、和 206 的关系

这份里的 `reverseList` 和 `p206` 是同一段代码（注释里也写了"直接拿过来用"）。
**206 是基础件、234 是它的一个组合应用** —— 这也是"一题一包"的好处：两个包里各自有一份 `ListNode`，
互不干扰；坏处是想复用 `reverseList` 时只能复制粘贴。

## 七、一句话记住

```
   快慢指针找中点 → 反转后半段 → 双指针比对 → 再把后半段翻回来；
   停止条件 fast.next != null && fast.next.next != null 让 slow.next 永远是后半段头（奇偶都成立）；
   比对用 p2 != null（奇数时后半段短一个）；提前 break 也要恢复 —— 他用 result 变量兜住了，实测 6 种形状全部完好；
   20,000 组与"字符数组两头比"0 差异；O(n)/O(1)，比 ArrayList 版省 O(n) 空间。
```
