# LeetCode 199 二叉树的右视图（每层最后一个，BFS 与 DFS 两条路）

> 对应程序：[LeetCode199_BinaryTreeRightSideView.java](./LeetCode199_BinaryTreeRightSideView.java)
> `main` 那棵树（1 的左 2、2 的左 4、4 的左 5，1 的右 3），实测：
>
> ```
> 右视图: [1, 3, 4, 5]
> ```
>
> 第 2 层只有 3 在右边；第 3、4 层右边全空，所以看到的是左边的 4 和 5。**右视图不等于"一路向右走"**。

---

## 一、复用层序遍历，只留每层最后一个

```java
while (!queue.isEmpty()) {
    int levelSize = queue.size();
    for (int i = 0; i < levelSize; i++) {
        TreeNode node = queue.poll();
        if (i == levelSize - 1) res.add(node.val);   // 本层最后一个
        if (node.left != null) queue.offer(node.left);
        if (node.right != null) queue.offer(node.right);
    }
}
```

和 `p102` 是同一套骨架，区别只有一行：`p102` 把每个值都收进 `level`，这里只在 `i == levelSize - 1` 时收一个。入队顺序仍然是**先左后右**，所以队尾就是这一层最右边的节点。

`levelSize` 同样必须冻结（见 `p102` 那份笔记：改成实时 `queue.size()` 会把层分错）。

## 二、三个变体实测

20,000 棵随机树，与两种独立参考对比：

```
他的 BFS 版          vs 每层取最后一个  = 0 差异
他的 BFS 版          vs DFS 先右后左    = 0 差异
```

| 变体 | 错多少 | 示例树 `(1,2,3,null,5,null,4)` |
| --- | --- | --- |
| 他的原版 | **0** | `[1, 3, 4]`（正确） |
| 入队改成先右后左 | 19,127 / 20,000 | 仍对，测不出 |
| 判断改成 `i == 0`（取每层第一个） | 19,127 / 20,000 | `[1, 2, 5]`（错） |
| 去掉判断、每层全收 | 19,129 / 20,000 | 变成层序遍历 |

第二行和第三行错的数量一模一样，因为它们是同一个错误的两种写法：**先右后左入队 + 取队尾**，等价于**先左后右入队 + 取队头**，都变成了左视图。示例树恰好左右对称到测不出来，随机数据里 95.6% 的树会露馅。

## 三、边界

| 输入 | 输出 |
| --- | --- |
| `null` | `[]` |
| 单节点 | `[值]` |
| 纯左斜链 1→2→3 | `[1, 2, 3]` |
| 示例 `(1,2,3,null,5,null,4)` | `[1, 3, 4]` |

纯左斜链那条最能说明"右视图"的含义：右边一个节点都没有，看到的全是左边的。

## 四、BFS 不怕深树

| 形状 | 节点数 | 他的 BFS | DFS 参考 |
| --- | --- | --- | --- |
| 满树（高 17） | 131,071 | 0 ms | 0 ms |
| 右斜链 | 50,000 | 正常 | `StackOverflowError` |
| 右斜链 | 100,000 | 正常（两次实测 5 ms / 0 ms） | `StackOverflowError` |

队列长度等于最宽一层，斜链上恒为 1，所以 10 万节点毫无压力；DFS 的栈深度等于树高，同样形状直接爆栈。这份和 `p102` 一样，是"深树优先选 BFS"的又一个例子。

时间 `O(n)`（每个节点进出队一次），空间 `O(w)`，w 是最大层宽。

## 五、一句话记住

```
   层序遍历骨架 + 一行 if (i == levelSize - 1)，levelSize 必须先冻结；
   右视图不是"一路向右"：main 那棵树给 [1,3,4,5]，纯左斜链给 [1,2,3]；
   20,000 组与"每层取最后"和"DFS 先右后左"两种参考都 0 差异；
   先右后左入队、或改成 i == 0，都错 19,127 / 20,000（变成左视图），
   而示例树 (1,2,3,null,5,null,4) 上 i==0 才测得出（给 [1,2,5]）；
   斜链 10 万节点 BFS 正常、DFS 爆栈。
```
