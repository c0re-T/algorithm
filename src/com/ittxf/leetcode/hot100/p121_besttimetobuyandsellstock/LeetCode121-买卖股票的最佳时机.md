# LeetCode 121 买卖股票的最佳时机（一次遍历记住历史最低价）

> 对应程序：[LeetCode121_BestTimeToBuyAndSellStock.java](./LeetCode121_BestTimeToBuyAndSellStock.java)
> `main` 跑两组示例，实测：
>
> ```
> 5
> 0
> ```

---

## 一、把"枚举买卖两天"换成"走到今天时最低价是多少"

```java
int minPrice = Integer.MAX_VALUE;
int maxProfit = 0;
for (int price : prices) {
    minPrice = Math.min(minPrice, price);
    maxProfit = Math.max(maxProfit, price - minPrice);
}
return maxProfit;
```

暴力是枚举所有 `j > i` 的 `prices[j] - prices[i]`，`O(n²)`。这里换个视角：**卖出日固定为今天，最佳买入日一定是今天之前的最低价**，于是两重循环塌成一重，`O(n)` 时间 `O(1)` 空间。

`minPrice` 初始化为 `Integer.MAX_VALUE` 保证第一天就会被替换；`maxProfit` 初始化为 0 表示"可以不交易"，所以单调递减的价格序列自然返回 0。

20,000 组随机（长度 0..40，一半价格 0..20、一半 -50..50）与 `O(n²)` 暴力对拍：**0 处差异**。另跑 20,000 组纯非负价格（0..10000）：**0 处差异**。

## 二、两行更新的顺序：题面范围内可换，放宽到负数就不行

先算利润再更新最低价，看起来会漏掉"今天就是最低价"的情况 —— 但那天 `price - minPrice == 0`，本来也刷新不了最大值。实测：

| 价格范围 | 交换顺序后的差异 |
| --- | --- |
| 全部 ≥ 0（题面范围） | **0 / 10,000** |
| 允许负数（-50..50） | **4,680 / 10,000** |

差别不在逻辑，在**溢出**：交换后第一个元素会算 `price - Integer.MAX_VALUE`。

| 输入 | 原版 | 交换后 | 说明 |
| --- | --- | --- | --- |
| `{-1,5}` | 6 | 6 | `-1 - MAX = -2147483648`，刚好不溢出 |
| `{0,5}` | 5 | 5 | `0 - MAX = -2147483647`，负数无害 |
| `{-50,-40}` | 10 | **2,147,483,599** | `-50 - MAX` 溢出成大正数 |

所以原写法"先更新最低价"顺手避开了这个坑，**但它不是靠逻辑正确性避开的，是靠价格非负**。

## 三、三个变体的实测差异

20,000 组非负价格（0..10000）：

| 变体 | 差异 | 原因 |
| --- | --- | --- |
| `maxProfit` 初始化成 `Integer.MIN_VALUE` | **472 / 20,000** | 全部是空数组，`{}` 返回 -2,147,483,648 |
| `minPrice = price`（去掉 `Math.min`） | **18,680 / 20,000** | 退化成恒返回 0 |
| `maxProfit = max(maxProfit, minPrice - price)` | **18,680 / 20,000** | 差值恒 ≤ 0，也退化成恒返回 0 |

第一行值得留意：初始化成 `MIN_VALUE` **只在空数组上出错**，非空数组哪怕单调递减也会被 0 覆盖掉，所以随机测试里错误率只有 2.4%，很容易漏。

## 四、边界与溢出

| 输入 | 结果 |
| --- | --- |
| `{}` | `0` |
| `{5}` | `0` |
| `{7,6,4,3,1}` | `0` |
| `{1,2}` | `1` |
| `{2,2,2}` | `0` |
| `null` | `NullPointerException: Cannot read the array length` |

题面限定 `0 <= prices[i] <= 10^4`，差值最大 10^4，int 绰绰有余。把价格放宽到 int 全域就会溢出：

| 输入 | 程序返回 | long 真值 |
| --- | --- | --- |
| `{Integer.MIN_VALUE, Integer.MAX_VALUE}` | **0** | 4,294,967,295 |
| `{-2000000000, 2000000000}` | **0** | 4,000,000,000 |

`price - minPrice` 溢出成负数，`Math.max(maxProfit, 负数)` 保住 0 —— **错得很安静，不会抛异常**。

入参只读：同一数组连调两次结果一致，数组内容不变。

## 五、实测代价

| 规模 | 一次遍历 | `O(n²)` 暴力 |
| --- | --- | --- |
| n=20,000 | **0 ms** | 15 ms |
| n=10,000,000 | **6 ms** | 跑不动（5×10¹³ 次比较） |

n=1e7、价格 0..10000 随机时实测最大利润 10000（几乎必然出现 0 和 10000 且顺序合适）。

## 六、一句话记住

```
   卖出日固定为今天、买入日取历史最低价，两重循环塌成一重，O(n) 时间 O(1) 空间；
   20,000 组随机与 O(n²) 暴力 0 差异（含负数价格）；
   两行更新顺序在价格非负时可换（0/10,000），允许负数就错 4,680/10,000 —— 首元素 price-MAX 溢出；
   maxProfit 初始化 MIN_VALUE 只在空数组出错（472/20,000），随机测试很容易漏；
   去掉 Math.min 或把差值写反，都退化成恒返回 0（各错 18,680/20,000）；
   {} / {5} / 递减序列都返回 0，null NPE，入参只读；
   {MIN,MAX} 溢出后安静地返回 0（真值 4,294,967,295）；
   n=20,000 一次遍历 0 ms vs 暴力 15 ms，n=1e7 只要 6 ms。
```
