# LeetCode 104 二叉树的最大深度（后序取 max，深链会爆栈）

> 对应程序：[LeetCode104_MaximumDepthOfBinaryTree.java](./LeetCode104_MaximumDepthOfBinaryTree.java)
> `main` 跑三棵树，实测：
>
> ```
> 空树: 0
> 树的最大深度: 3
> 完全二叉树的最大深度: 3
> ```

---

## 一、递归定义

```java
if (root == null) return 0;
if (root.left == null && root.right == null) return 1;
int leftDepth = maxDepth(root.left);
int rightDepth = maxDepth(root.right);
return Math.max(leftDepth, rightDepth) + 1;
```

最大深度 = `max(左子树深度, 右子树深度) + 1`；空树是 0。这是典型的后序遍历：先拿到两个孩子的结果，再决定自己的。

中间那行 `if (叶子) return 1;` 可以删掉：叶子节点的两个孩子都是 null，会走 `Math.max(0, 0) + 1 = 1`，结果完全一样。它只是少两次函数调用。

`main` 里的 `1 -> 右 2 -> 左 3` 三条边、三个节点，深度 3；7 节点满树深度 3。

## 二、随机对拍

1..50 个节点的随机树，固定种子 20,000 组，与"队列逐层计数"的 BFS 参考实现对比：

```
深度不一致 = 0
```

BFS 每弹空一层 `depth++`，和递归的 `max+1` 是同一件事的两种写法。

## 三、递归深度：满树没事，斜链有事

| 形状 | 节点数 | 深度 | 结果 |
| --- | --- | --- | --- |
| 右斜链 | 5,000 | 5,000 | 5,000 |
| 右斜链 | 10,000 | 10,000 | 10,000 |
| 右斜链 | 20,000 | 20,000 | 20,000 |
| 右斜链 | 50,000 | 50,000 | `StackOverflowError` |
| 满二叉树 | 1,048,575 | 20 | 20，**2.2 ms** |

递归栈的深度等于**树高**，不是节点数。100 万节点的满树高度只有 20，安全；一条 5 万节点的链高度 5 万，栈先撑不住。判断风险要看形状，不要只看 n。

## 四、代价

每个节点访问一次：`O(n)` 时间；栈 `O(h)`。BFS 版是 `O(n)` 空间（最后一层最多 n/2 个节点），深树反而更安全。

## 五、一句话记住

```
   maxDepth = max(左, 右) + 1，空树 0；
   叶子那行 return 1 可以删，删了走 max(0,0)+1 结果相同；
   20,000 组与 BFS 0 差异；
   栈深度 = 树高：满树 100 万节点（高 20）2.2 ms，5 万节点的斜链直接爆栈；
   O(n) 时间、O(h) 栈。
```
