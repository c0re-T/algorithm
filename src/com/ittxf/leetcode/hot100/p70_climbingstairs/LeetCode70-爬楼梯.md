# LeetCode 70 爬楼梯（滚动变量代替 DP 数组）

> 对应程序：[LeetCode70_ClimbingStairs.java](./LeetCode70_ClimbingStairs.java)
> `main` 跑三组示例，实测：
>
> ```
> 2
> 3
> 5
> ```

---

## 一、三个 int 就够，不需要 `dp[n+1]`

```java
if (n <= 2) return n;
int prev1 = 1, prev2 = 2, curr = 0;
for (int i = 3; i <= n; i++) {
    curr = prev1 + prev2;
    prev1 = prev2;
    prev2 = curr;
}
return curr;
```

`dp[i] = dp[i-1] + dp[i-2]`，只依赖前两项，所以整张表可以压缩成两个变量。时间 `O(n)`，空间 `O(1)`。

这题的答案就是斐波那契：`climbStairs(n) == F(n+1)`（`F(1)=F(2)=1`）。用 long 算术独立算 `F(n+1)` 对拍 n=1..45：**0 处不一致**；再用"把 n 拆成若干个 1 和 2"的递归枚举对拍 n=1..25：**0 处不一致**。

## 二、`n <= 2` 这行守卫是必需的

删掉它之后，n=1 和 n=2 都不会进入循环，`curr` 保持初始值 0：

| n | 原版 | 删守卫 |
| --- | --- | --- |
| 1 | 1 | **0** |
| 2 | 2 | **0** |
| 3 | 3 | 3 |

n=1..45 里刚好错 **2 处**，就是这两个。

## 三、滚动的两行赋值不能交换顺序

```java
prev1 = prev2;   // 先让 prev1 接过旧的 prev2
prev2 = curr;    // 再让 prev2 接过新值
```

写成 `prev2 = curr; prev1 = prev2;` 后，`prev1` 拿到的是**新值**而不是旧值，递推退化成"每轮翻倍"：

| n | 原版 | 交换后 |
| --- | --- | --- |
| 3 | 3 | 3 |
| 4 | 5 | **6** |
| 5 | 8 | **12** |
| 6 | 13 | **24** |
| 10 | 89 | **384** |

n=1..45 错 **42 处**，第一处在 n=4。注意 n=3 恰好还对，所以只测示例会漏掉这个 bug。

反过来，`return curr` 改成 `return prev2` 是**等价的**（循环末尾刚做过 `prev2 = curr`），n=1..45 **0 处差异**。

## 四、int 在 n=46 溢出

| n | 程序返回 | long 真值 |
| --- | --- | --- |
| 44 | 1,134,903,170 | 1,134,903,170 |
| **45** | **1,836,311,903** | 1,836,311,903 |
| 46 | **-1,323,752,223** | 2,971,215,073 |
| 47 | 512,559,680 | 4,807,526,976 |
| 48 | -811,192,543 | 7,778,742,049 |

**n=45 是最后一个正确答案**，n=46 起变成负数。题面限定 `1 <= n <= 45`，正好卡在 int 边界内 —— 这不是巧合，是出题人按 int 上限挑的。

## 五、边界与实测代价

| 输入 | 结果 |
| --- | --- |
| n=0 | `0` |
| n=-1 | `-1` |
| n=-5 | `-5` |

`n <= 2` 直接 `return n`，所以 0 和负数原样返回，没有任何校验。题面保证 n≥1，越界行为不必当真。

耗时（5,000,000 次调用，n 在 1..45 之间循环）：

| 版本 | 耗时 |
| --- | --- |
| 滚动变量 | **22 ms** |
| `dp[n+1]` 数组 | 97 ms |

n 接近 1,000,000 时各调 200 次：滚动 **42 ms**，数组版 **236 ms**，数组版还要额外 4 MB 堆。

一个测量陷阱：**参数写成常量会被 JIT 提出循环**。同样 5,000,000 次 `climbStairs(45)` 只花 4 ms —— 那不是算法快，是循环体被优化掉了，必须让 n 变化才量得到真实代价。

## 六、一句话记住

```
   dp[i]=dp[i-1]+dp[i-2] 只依赖前两项，三个 int 滚动即可，O(n) 时间 O(1) 空间；
   答案就是 F(n+1)，long 对拍 n=1..45 与递归枚举 n=1..25 都 0 差异；
   `n<=2` 守卫删掉错 2 处（n=1、n=2 都返回 0）；
   滚动两行交换顺序错 42/45（n=4 起 5→6、89→384），但 return prev2 等价；
   n=45 是最后一个正确 int 答案 1,836,311,903，n=46 溢出成 -1,323,752,223；
   n=0/-1/-5 原样返回，无校验；
   5e6 次调用滚动 22 ms vs 数组 97 ms，常量参数会被 JIT 提走、量不出真实耗时。
```
